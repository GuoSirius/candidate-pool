# 形态选股（Pattern Screener）方案与口径

> 2026-11-09 落地。用户拍板：四类形态、双引擎、默认全市场、报告可过滤、加参考价位与 mini K 线、定时任务 PAUSED 手动触发。

## 1. 需求与边界

| 项 | 结论 |
|---|---|
| 目标 | 从全市场找出「当下处于指定形态」的票，产出数据归档 + 可过滤 HTML 报告 |
| 四类形态 | 强势平台、N字二波、老鸭头、VCP突破 |
| 扩展性 | 新增形态优先只改 `eod/pattern.templates.json`，不改代码 |
| 默认范围 | `universe`（全市场盲扫），`--scope watchlist` 可回退观察池 |
| 调度 | PAUSED 状态，手动随时执行；不自动跑、默认不推送 |
| 明确不做 | 不自动调权重、不自动改模板、不产出买卖建议 |

## 3. 双引擎架构

| 引擎 | 形态 | 判定方式 | 新增成本 |
|---|---|---|---|
| `template` | 强势平台 / N字二波 | 启动日锚点对齐 + 尺度无关特征向量 + 加权距离 → 0–100 匹配分 | 只加一条 JSON（模板票 + 起止日 + 权重），跑一次 `pattern:calibrate` |
| `rule` | 老鸭头 / VCP突破 | 参数化门槛制，逐项 `ok / value / threshold` 可解释 | 需在 `pattern_engine.js` 注册一个规则函数，阈值仍留在 JSON |

**为什么不用 DTW**：对价格尺度、窗口长度、除权敏感，且报告无法解释「为什么像」。特征向量每项都是百分比 / 倍数 / 天数 / 次数，报告可逐项展开。

| 特征键 | 含义 |
|---|---|
| `launchVolX` / `launchChg` / `launchBreak` | 启动日放量倍数 / 涨幅 / 相对前 20 日高的突破幅度 |
| `windowDays` / `cumChg` / `boxAmp` | 窗口交易日数 / 累计涨幅 / 箱体振幅 |
| `minVsMA20` / `aboveMA20Now` / `maxDrawdown` | 窗口内最低距 MA20 / 现价距 MA20 / 最大回撤 |
| `volMaintain` / `volDecay` | 启动后均量 ÷ 启动前均量 / 末 3 日量 ÷ 窗口前 3 日量 |
| `limitUpCount` / `recentSurge` | 涨停次数 / 近 3 日是否有放量上攻 |

容差 = `max(|target| × 0.6, 键下限)`，可在定义里用 `tolerance` 显式覆盖；缺数据项计 0 分但保留权重，绝不静默给高分。

## 4. 数据流与工程约束

| 阶段 | 做法 | 实测 |
|---|---|---|
| ① 全市场快照 | `qt.gtimg.cn` 批量报价按代码段枚举 | 6181 只有效报价，~500 批 |
| ② 宽松粗筛 | 只排除 ST/停牌/次新、价格 2–300、市值 10–2000 亿、换手 ≥0.5%、量比 ≥0.3、成交额 ≥500 万 | 6181 → 4804 只 |
| ③ 逐票日 K | `ifzq fqkline` 前复权 260 根、四端点降级、锚定日截断 | 4804 次请求，并发 6 |
| ④ 双引擎 | 逐票滑窗找启动日 → 特征 → 匹配分 → 阶段 → 参考价位 | 纯本地计算 |
| ⑤ 上榜/游资 | 仅命中票调东财龙虎榜 + 席位明细，失败留空不阻断 | 低频，几十次 |

> **粗筛不按成交额/涨幅取 TopN**：形态票常处于缩量整理，按活跃度排序会把「启动后横住」的票全部误杀。
> **健康度闸门**：K 线失败率 >20% 直接退出码 1，不生成报告、不覆盖归档、不推送，避免「今日 0 命中」的假报告。

### 4.1 锚定日口径（2026-11-10 统一，2026-11-11 补充完善）

所有实时报告的「锚定日」统一为**行情时间戳众数 `marketDate`**（腾讯 `qt.gtimg.cn` 批量报价的 `stamp` 字段众数，即行情实际交易日），零维护、天然覆盖法定节假日/调休/临时休市。与 `lastClosedTradingDay`（纯日历推算）的区别见上方 FAQ。

**各时段运行行为（用户 2026-11-11 拍板）**：

| 报告/脚本 | 开盘前（<9:30） | 盘中 | 收盘后（≥15:00） | 上榜（龙虎榜） |
|---|---|---|---|---|
| 形态选股（pattern） | 锚定上一交易日（完整 K、走缓存） | 锚定当日实时（含半截 K、不读/不写缓存） | 锚定当日收盘固定口径（K 完整、**可读写当日缓存**） | 取锚定日榜；今日榜未出（~17:30 前出）→ 自动回退上一交易日，`billboard.date` 标注榜单日期 |
| 尾盘（tail，观察/正式/盘中） | 不带 `--force` 直接拒绝（保护性守卫）；`--force` → 锚上一交易日 | 锚定当日实时 | 宽限期内锚当日；`--force` 补跑同 | `lastClosedTradingDay(now)`：盘中/收盘早期自动=上一交易日，盘后重跑自动=今日 |
| 盘前选股（preopen，9:20–9:35） | ——（本身就是盘前任务，锚当日行情日） | 窗口外跳过；`--force` → 锚当日 | `--force` → 锚当日 | 候选级昨日榜（东财） |
| 次日候选池（gen_candidates） | 锚上一交易日 | 锚当日实时（盘中语义 2026-11-11 确认） | 锚当日收盘 | 候选级昨日榜 |
| 游资（hotmoney_scan） | 快照失败兜底 `lastClosedTradingDay` | 锚当日 | 锚当日；`boardReadyFrom`(17:30) 前当日榜未出齐→回退上一交易日 | 同左 |
| 盘前基线（preopen-baseline 缓存） | —— | 一般不跑；跑了→文件命名当日 | **文件命名=服务交易日**：15:00 收盘后跑→命名下一交易日；15:00 前跑（含 03:00）→命名当日；内容内嵌 `dataDate`=数据日，读侧昨收抽样校验 | —— |

**live 锚定来源**：全市场快照 `marketDate`（数据驱动）；`--date` 指定日；`--offline`/`--replay` 取存档/缓存日；快照失败回退 `lastClosedTradingDay`。

**关键规则**：A 股周六/周日永远休市；调休补班日即使落在周末也休市，对开市判定无任何影响（日历只登记法定节假日）。盘中锚定当日时禁用 K 线缓存读写，避免污染历史归档；收盘后（≥15:00）K 线已完整，允许读写当日缓存。龙虎榜未出时的「回退上一交易日」属设计内行为（与尾盘/游资同口径），报告以榜单日期标注。盘前基线缓存文件名仅是语义标签（日历口径），读侧按内容 `dataDate` + 昨收校验定位与验证，节假日错名不影响正确性。`marketDate` 与 `lastClosedTradingDay` 的分工：实时报告一律优先 `marketDate`（更准确、零维护、覆盖临时休市），仅在快照失败或无行情上下文时回退日历口径。

## 5. 参考价位口径（量化参考位，非投资建议）

| 项 | 公式 |
|---|---|
| 支撑位 | `min(max(窗口最低收盘, MA20×0.98), 现价×0.98)` |
| 推荐买入区间 | `[支撑位, 现价×(1+2%)]`；现价距支撑 >8% 时标「等回踩」，上沿改为 `支撑位×1.02` |
| 止损 | `支撑位×(1−2%)` |
| 止盈 | `现价 +(现价−止损)×2`（**按现价入场**、盈亏比 2:1；买入区间是回踩挂单参考，两者口径不同） |

参数集中在 `pattern.config.js` 的 `price`，可调 `chasePct / stopBufferPct / rewardRatio / maxChasePct`。

## 6. 报告：过滤项与表头

| 过滤组 | 取值 |
|---|---|
| 形态（新增，只用形态名） | 全部 / 强势平台 / N字二波 / 老鸭头 / VCP突破 / 多形态共振（≥2 类） |
| 阶段 | 全部 / 启动当日 / 整理蓄势 / 二次启动（破位默认排除） |
| 匹配分 | 不限 / ≥90 / ≥80 / ≥70 |
| 质量（沿用盘前） | 上榜 / 游资 / **一线 / 二线 / 避坑** / 按游资名动态细分 / 组内第一 / 组内前三（**过滤项是两个 chips，展示只有一列**，与盘前一致） |
| 行业 | 全部 + 当日命中动态生成 |
| 视图 | 按综合分 / 按形态（按主形态分组）/ 按行业 |
| 开关 | 分项特征 6 列展开 |
| 组合 | 各组 AND；选中形态/行业时自动切对应视图 |

> 游资层级（一线 / 二线 / 避坑）是跨报告统一过滤项，口径见 README「游资层级过滤」。

| 表头分组 | 列 |
|---|---|
| 基础 | `#` / 标的 / **mini K线** / 行业 / 板块 / 现价 / 涨跌% / 量比 / 换手% / 市值·流通 |
| **价位（基础表头之后）** | **推荐买入区间 / 止损 / 止盈** |
| 形态 | 形态(多标签) / 匹配分 / 窗口(启动日·天数) / 累计涨幅 / 距MA20 / 阶段 |
| 关联（**位置：紧跟形态列之后**） | 连板 / **上榜（同一列）** —— 复用盘前的 `billboardCell`：一格内 = 上榜标记 + 席位明细/金额/分层 |
| 展开（开关） | 启动放量 / 累计涨幅 / 箱体振幅 / 最低距MA20 / 量能维持 / 最大回撤 |
| 汇总 | 综合分 / 标签（可观察 / 等回踩） |

mini K 线为内联 SVG（零外链），涨红跌绿，虚线标出启动日。报告沿用盘前的双语 / 深浅色 / 单文件内联范式。

**全报告统一列位（2026-11-09）**：mini K 线一律紧跟「标的 / 代码」列，位于所有数值列之前，避免一份在前一份在后。
实现收在 [`eod/lib/kline_spark.js`](../../eod/lib/kline_spark.js)：CSS、SVG、代码归一化、日 K 索引共用一份，六个 HTML 生成器只各加一个单元格。
数据源是 `eod/data/pattern/pattern-kline-<日>.json`（形态管道每天落的全市场前复权日 K 日档，被 gitignore）；缺档或缺票时该格显示「—」，不编造数据、不阻断报告。
盘前主表按 `anchor` 截断、游资近 N 日表按每行 `date` 截断，避免把重渲染当天的收盘 K 线画进历史记录（前视偏差）。

## 7. 产物与命令

| 路径 | 内容 |
|---|---|
| `eod/data/pattern/pattern-<日>.json` | 命中明细、贴线样本、漏斗统计、runs 留痕（提交 git） |
| `eod/data/pattern/pattern-kline-<日>.json` | 粗筛入围票日 K + 报价快照（体积大，gitignore，供 `--replay`） |
| `eod/reports/pattern/pattern-<日>.html` | 可过滤报告（提交 git） |
| `eod/data/perf-weekly.json → pipelines.pattern` | 按形态的 T+1/T+3 胜率（由 backfill 合并写入） |

| 命令 | 用途 |
|---|---|
| `npm run pattern` | 全市场正式跑（手动触发入口） |
| `npm run pattern -- --scope watchlist` | 观察池快速调试 |
| `npm run pattern -- --date 2026-11-06` | 指定锚定日 |
| `npm run pattern -- --limit 300` | 粗筛后截断调试 |
| `npm run pattern:replay` | 从当日 K 线缓存零网络重算（调阈值用） |
| `npm run pattern -- --refresh` | 忽略缓存强制重抓 |
| `npm run pattern:calibrate` | 改模板票/起止日后重算标尺 |
| `npm run pattern:backfill` | 补 T+1/T+3 并按形态聚合胜率 |
| `npm run pattern:selftest` | 23 项离线自测（模板票必须满分） |

## 8. 新增形态的操作

| 情形 | 操作 |
|---|---|
| 有模板票（「找出像 XXX 从某日起的走势」） | 在 `eod/pattern.templates.json` 加一条 `engine: "template"`，填 `template.code/from/to`、`launch`、`window`、`weights` → 跑 `pattern:calibrate` → 跑 `pattern:selftest` |
| 有明确定义（如「杯柄形态」） | 在 `pattern_engine.js` 新增规则函数并注册 `RULES`，阈值写进 JSON 的 `gates` |
| 只想临时试参数 | 复制定义到 `eod/data/pattern-templates.json`（工作目录覆盖文件优先），不污染包内默认 |

## 9. 已知偏差与风险

| 项 | 说明 |
|---|---|
| 前视偏差 | 模板起点由人工事后指定（10/22 / 9/16），回测必须按「当日可得信息」重新判定 |
| 模糊匹配 | 相似度非确定性规则，阈值需「模板票满分 + 全市场命中数落在合理区间（建议 20–80 只）」双向校准 |
| 复权漂移 | 前复权序列随新除权变化；归档需记录锚定日，校准数据要定期重跑 |
| 数据源 | 东财龙虎榜/席位可能临时封 IP，相关列留空；腾讯 WAF 由四端点降级 + 失败率闸门兜底 |
| 样本门禁 | 有 verdicts 的交易日 <20 时，报告「形态胜率」只显示「待积累」，不给命中率结论 |
| 可成交性 | 涨停/一字板可能买不到，参考价位不保证成交；本报告不构成投资建议 |
