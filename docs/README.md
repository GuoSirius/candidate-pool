## 命名规范

| 规则 | 说明 |
|------|------|
| 一级目录 | 英文短横线 slug（如 `eod-tail-screener`），避免中文路径在各系统 / Git / 命令行下的编码问题 |
| 文件命名 | `两位序号-类型.md`，序号决定阅读顺序 |
| 类型白名单 | `需求` / `方案` / `计划` / `待确认` / `评审` / `复盘` |
| 索引 | 每新增一篇，在本文件下方「文档索引」补一行；索引是唯一入口 |
