# 评论（备注）与分组管理 —— 方案

一句话：把详情页里「只读展示」的**备注**和**分组**补上**可写**能力，让使用者能对某只票记评论、加备忘、建分组归类。

## 1. 需求

| 编号 | 需求 | 说明 |
|------|------|------|
| N-01 | 写评论 / 备忘 | 在某只票下新增一条备注，可选类型（评论 / 备忘），可绑定到某次入选（锚定日）或作为通用备注 |
| N-02 | 编辑与删除备注 | 已写备注可改内容、可删 |
| N-03 | 新建分组 | 建分组（名称唯一），可带颜色与说明 |
| N-04 | 改名 / 改色 / 删除分组 | 删除分组时同时解除票-组关联，不删票 |
| N-05 | 把票加入分组 | 一只票可加入多个分组，可带「入组备注」 |
| N-06 | 把票移出分组 | 解除单只票与某分组的关联 |
| N-07 | 按分组浏览 | 已有 `GET /api/stock-base?group=` 可筛；本次不新增页面 |
| N-08 | 写入必须可控 | 站点是公开的，**写接口不能裸奔**，见第 4 节 |

## 2. 数据模型

表已在 `db/schema.sql` 里建好，**本次不新增表、不改结构**，只补读写接口。

| 表 | 用途 | 关键列 |
|----|------|--------|
| `stock_note` | 评论 / 备忘 | `code`、`anchor_date`(可空)、`type`、`content`、`created_at` |
| `watch_group` | 分组 | `id`、`name`(唯一)、`color`、`description`、`created_at` |
| `pick_group_rel` | 票 ↔ 组（多对多） | 主键 `(code, group_id)`、`note`、`created_at` |

时间字段统一由 Worker 侧生成「北京时间字符串」`YYYY-MM-DD HH:mm:ss`，与现有写入口径一致。

`✅ 已有` / `➕ 本次新增`。全部返回统一信封 `{ code, message, data }`。

|------|------|------|------|------|

### 校验口径

| 项 | 规则 | 违反时 |
|----|------|--------|
| `code` | 非空，`^(sh|sz|bj)\d{6}$` | 10003 参数错误 |
| `content` | 非空，长度 ≤ 500 | 10003 |
| `type` | 仅 `comment` / `memo`，缺省 `comment` | 10003 |
| `anchor_date` | 空或 `^\d{4}-\d{2}-\d{2}$` | 10003 |
| 分组 `name` | 非空，长度 ≤ 30，唯一 | 10003 / 冲突 10001 |
| `color` | 空或 `^#[0-9a-fA-F]{6}$` | 10003 |

## 4. 写鉴权方案

站点 `*.pages.dev` 是**公开可访问**的，写接口一旦放开就等于谁都能改数据，所以必须挡一层。

| 方案 | 成本 | 安全性 | 适用 |
|------|------|------|------|
| **A. 共享令牌**（本次采用） | 低：`wrangler secret put WRITE_TOKEN` | 够用：私密随机串，前端存 localStorage，请求带 `x-write-token` | 自用 / 小范围 |
| B. Cloudflare Access | 中：配 Zero Trust 策略 | 高：邮箱 / SSO 门禁，但会对整站或整段路径生效，配置在 Cloudflare 控制台 | 多人协作 |
| C. 仅本地可用 | 最低：不部署写接口 | 最高：线上只读 | 只想本地整理 |

**本次按 A 实现，并做到「安全默认」**：

| 情形 | 行为 |
|------|------|
| Worker 未配置 `WRITE_TOKEN` | 所有写接口直接返回 10001 + 明确文案「写接口未启用（未配置 WRITE_TOKEN）」，前端展示为**提示**而非报错 |
| 配置了 `WRITE_TOKEN`，请求未带 / 带错 | 返回 10001 + 「写令牌校验失败」 |
| 令牌正确 | 正常执行 |

> B / C 不需要改代码即可叠加：C 只需不配置 `WRITE_TOKEN`；B 只需在 Cloudflare 控制台对 `/api` 加 Access 策略。

## 5. 前端交互

| 位置 | 交互 |
|------|------|
| 顶栏 | 新增「写权限」入口：未配置时提示如何启用；已配置时可粘贴 / 清除令牌 |
| 详情页 · 备注 | 新增表单（类型 + 内容 + 可选锚定日）；每条备注带「改」「删」；空态给出引导文案 |
| 详情页 · 分组 | 下拉选择要加入的已有分组 / 就地新建分组；已属分组每项带「移出」 |
| 未启用写接口 | 编辑控件禁用 + 展示第 4 节的启用步骤，不弹错误 |

## 6. 边界（本次不做）

| 不做 | 原因 |
|------|------|
| 多用户 / 登录体系 | 自用工具，共享令牌足够；要做则走方案 B |
| 分组页 / 分组看板 | 现有 `?group=` 已可筛，等真需要再加 |
| 备注富文本 / 附件 | 纯文本已满足「记一笔」的诉求 |
| 批量给多只票加同一分组 | 需求未提，避免范围蔓延 |
